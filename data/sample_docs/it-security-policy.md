# IT Security Policy

All company laptops must use full-disk encryption and lock automatically after five minutes of inactivity. Operating system and browser updates must be installed within seven days of release.

Passwords must be at least 14 characters long and stored only in the approved password manager. Multi-factor authentication is mandatory for email, source code hosting and cloud consoles. Never share credentials, API keys or tokens in chat, email or source code.

Report suspected phishing emails with the "Report phishing" button. Lost or stolen devices must be reported to the IT service desk within one hour so the device can be wiped remotely. Personal devices may access company email only through the managed mobile app.
